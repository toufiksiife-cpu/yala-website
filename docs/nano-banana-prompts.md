## Tips for best results with any AI image tool

- Always include the brand colors explicitly (#1E456F navy, #7CB73E green, etc.).
- Add "no AI artifacts, no extra fingers, no distorted text, no warped books" to avoid common errors.
- Request "realistic textures" rather than "cartoon" or "illustration" if you want credibility.
- Use "shallow depth of field" for hero photos; "flat-lay" for decorative cards.
- For people: specify age, clothing style, and natural expression to avoid generic stock looks.
- Always review the result before deploying — delete any image that looks artificial or doesn't match your school's real identity.
